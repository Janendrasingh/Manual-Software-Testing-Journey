# 🧪 Manual Software Testing Journey

Welcome to my **Manual Software Testing Journey** repository!

This repository documents my learning journey in Software Testing and Quality Assurance (QA). My goal is to develop a strong understanding of software testing concepts, methodologies, practical testing techniques, and industry-standard tools.

I will maintain organized notes, practical examples, test cases, test scenarios, bug reports, and hands-on projects as I progress through the modules.

---

## 🎯 Learning Objectives

- Understand Software Testing fundamentals and concepts.
- Learn SDLC and STLC methodologies.
- Understand different software testing types and techniques.
- Learn how to write effective test scenarios and test cases.
- Understand defect identification, reporting, and tracking.
- Gain practical experience with Agile and Scrum methodologies.
- Learn Jira for project and defect management.
- Develop real-world Manual Testing skills.
- Build a foundation for Automation Testing.

## Module 2: Software Testing Project

This module focuses on understanding how testing is performed in a real-world software project.

### Topics Covered

1. Project Introduction
2. Understanding Functional Requirements from FRS
3. Creating Test Scenarios
4. Creating Test Cases
5. Test Execution
6. Bug Reporting and Tracking
7. Test Sign-off

### Practical Activities

- Analyze project requirements.
- Identify positive and negative test scenarios.
- Write detailed test cases.
- Execute test cases.
- Record actual and expected results.
- Identify and report defects.
- Track defect status.
- Prepare test execution reports.
